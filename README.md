# Projected Textures

A Minecraft Java Edition shaderpack that uses screen UVs for block textures<br>
Original code by [Acientkingg](https://github.com/Ancientkingg) on GitHub [here](https://github.com/Ancientkingg/shader-shenanigans/tree/master/projected_blocks)<br>
This was translated from Minecraft core shaders into glsl; the resource packs no longer function in the latest versions of Minecraft.<br>

# Usage

Press the green `Code` button and select `Download Zip`<br>
Drag the zip into your Minecraft `shaderpacks` folder with Optifine (untested) or Iris installed.<br>

<details>
<summary>oh no! i dont know where my shaderpacks folder is!</summary>
Assuming you are using Minecraft official launcher, the defualt path is
  
- Windows: `%Appdata%\.minecraft\shaderpacks`<br>
- macOS: `~/Library/Application Support/minecraft/shaderpacks`<br>
- Linux: `~/.minecraft/shaderpacks`<br>
